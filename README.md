# student-record-management-system

## Introduction
This project demonstrates the use of arrays in C++ through a Student Record Management System.

## Objectives
- Store students' examination scores using arrays.
- Display the scores entered.
- Calculate the total and average scores.
- Identify the highest and lowest scores.

## Programming Language
C++

## Data Structure Used
Array

## Project Files
- Arrays_Assignment_CPP.docx: The written assignment.
- student_records.cpp: The C++ source code.
- README.md: Project description and instructions.

## How to Run the Program
1. Download the student_records.cpp file.
2. Open it using a C++ compiler.
3. Compile and run the program.
4. Enter the number of students.
5. Enter each student's score.
6. View the total, average, highest, and lowest scores.

## Conclusion
This project demonstrates how arrays can be used to store and process student examination scores efficiently.
